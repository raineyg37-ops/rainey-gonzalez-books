# Rainey Gonzalez Books

Free author landing page for Rainey Gonzalez's paperback catalog. The site is static, has no cookies or third-party analytics, and links each title to its exact Amazon ASIN.

Published at https://raineyg37-ops.github.io/rainey-gonzalez-books/ via GitHub Pages from `main` at repository root.

Before changing a product description, image, or retail URL, verify it against the current live paperback edition. Campaign state and metrics live in the Kid's Books workspace's `promotion/campaign-state.json`; page views or outbound clicks must not be treated as sales without independent attribution.
